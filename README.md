# Water Potability Prediction

## Project Overview
Water Potability Prediction is a Machine Learning project that aims to predict whether water is safe for human consumption based on its chemical and physical properties.

The project uses data analysis and machine learning techniques to explore water quality features and build predictive models.

## Objectives
- Analyze water quality data.
- Perform data cleaning and preprocessing.
- Handle missing values.
- Explore relationships between different water quality features.
- Apply machine learning techniques to predict water potability.
- Evaluate model performance.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Dataset
The dataset contains water quality parameters such as:
- pH
- Hardness
- Solids
- Chloramines
- Sulfate
- Conductivity
- Organic Carbon
- Trihalomethanes
- Turbidity

The target variable is `Potability`, which indicates whether the water is potable or not.

## Project Workflow
1. Data loading
2. Exploratory Data Analysis (EDA)
3. Data preprocessing
4. Handling missing values
5. Feature analysis
6. Model training
7. Model evaluation

## Project File
`water_potability_smote.ipynb` – Jupyter Notebook containing the project implementation.

## How to Run
1. Clone or download this repository.
2. Install the required Python libraries.
3. Open the notebook using Jupyter Notebook or Google Colab.
4. Run the notebook cells in sequence.
